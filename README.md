# Advanced Security Patterns Frontend

Next.js application for testing JWT, RBAC/ACL, and Secure APIs.

## Features

- ✅ Interactive Topic Pages
- ✅ Real API Testing
- ✅ Token Management
- ✅ Role-based UI
- ✅ Responsive Design with Tailwind CSS

## Pages

- `/` - Home page with topic overview
- `/topic1` - JWT Authentication testing
- `/topic2` - RBAC & ACL testing
- `/topic3` - Secure API testing

## Getting Started

```bash
npm install
npm run dev
```

Visit: http://localhost:3000
